# UI Components

GitHub Pages-ready UI experiments.

## Pages

- `/` - component index
- `/compose-ai-box/` - compose message AI box prototype

## Upload Through GitHub Website

1. Open your `ui-components` repository on GitHub.
2. Click **Add file**.
3. Click **Upload files**.
4. Upload:
   - `index.html`
   - the whole `compose-ai-box` folder
5. Click **Commit changes**.

Then turn on GitHub Pages:

1. Go to **Settings**.
2. Click **Pages** in the left sidebar.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Set **Branch** to `main`.
5. Set the folder to `/root`.
6. Click **Save**.

Your site should become available at:

`https://aaaronvale.github.io/ui-components/`

The compose box should be available at:

`https://aaaronvale.github.io/ui-components/compose-ai-box/`
